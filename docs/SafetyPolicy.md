# Safety Policy

1. Always prioritize life-threatening symptom escalation.
2. Always display a disclaimer that AI guidance is not professional medical care.
3. Provide safer first-aid style suggestions only.
4. Never delay emergency action for optional details.
5. If user appears critical:
   - trigger emergency panel immediately,
   - provide ambulance number,
   - provide nearest reachable hospital contact.
6. If hospital is unreachable/closed, automatically route to next valid option.
